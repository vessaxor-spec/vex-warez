# Vex Warez

> Skills refined through use. Patterns that proved useful. Builds worth sharing.

Vex Warez is the public artifact layer of VEX — a personal AI system 
built around structure, composability, and deliberate reasoning.

Everything here started as something built for a real purpose, 
then shaped until it was worth releasing.

---

## What is VEX?

VEX is a personal AI system being built from the ground up around one idea:
that structured, composable reasoning produces better outcomes than improvisation.

Vex Warez shares selected components of that system as they mature.

---

## What You'll Find Here

| Component | Description |
|-----------|-------------|
| `skills/` | Modular AI skill definitions |
| `frameworks/` | Structured reasoning and constraint systems |
| `patterns/` | Agent orchestration and routing patterns |
| `primitives/` | Reusable reasoning building blocks |

Designed to be adaptable across AI stacks — regardless of technical background.

---

## Design Principles

- Structure over improvisation
- Precision over verbosity
- Explicit boundaries over ambiguity
- Composability over monoliths
